# Rank Math SEO Quick Fix - Farm Insurance Page

## Current Issue: Score is 6/100
The main problem is that **Focus Keyword is empty** and SEO fields need to be configured.

---

## Quick Fix Steps (5 minutes)

### Step 1: Set Focus Keyword ✅
In the Rank Math SEO box:

1. **Focus Keyword field** - Enter:
   ```
   Farm Insurance Sioux Falls
   ```
   OR if you prefer:
   ```
   farm insurance sioux falls
   ```
   (Use the primary keyword you want to rank for)

2. **Click outside the field** or wait - Rank Math will start analyzing

### Step 2: Edit SEO Title ✅
1. Click **"Edit Snippet"** button in the preview section
2. In the **SEO Title** field, enter:
   ```
   Farm Insurance Sioux Falls SD | Farm & Ranch Insurance South Dakota
   ```
   (This includes your focus keyword at the beginning!)

### Step 3: Edit Meta Description ✅
1. Still in the **"Edit Snippet"** area
2. In the **Meta Description** field, enter:
   ```
   Comprehensive farm & ranch insurance in Sioux Falls, SD. Protect your farmhouse, barns, equipment, livestock, and liability. Get free quotes from Sperling Insurance serving South Dakota farms.
   ```
   (Make sure it includes "Farm Insurance Sioux Falls" naturally)

3. **Click "Update Snippet"** or save

### Step 4: Update URL Slug ✅
1. Click **"Edit"** next to the permalink (below the page title)
2. Change from `/farm-insurance/` to:
   ```
   /farm-insurance-sioux-falls/
   ```
   OR
   ```
   /farm-ranch-insurance-sioux-falls/
   ```
   (Include your focus keyword in the URL)

3. Click **"OK"**

### Step 5: Verify Content Has Keyword ✅
Your content should already have "Farm Insurance Sioux Falls" in it. If you added content to the editor following the guide, it should be there. 

If not, make sure your editor content includes:
- "Farm Insurance Sioux Falls" in the first paragraph
- "Farm Insurance Sioux Falls" in headings (H2, H3)
- "Farm Insurance Sioux Falls" multiple times throughout

### Step 6: Save/Update Page ✅
1. Click **"Update"** button (top right)
2. Wait a few seconds
3. Check Rank Math score again - should improve significantly!

     - In at least one H2 or H3 heading

2. **Internal Links:**

4. **Images with Alt Text:**
