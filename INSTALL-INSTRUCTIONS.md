## ⚡ Method 1: Upload & Run (Easiest - 2 Minutes)

### Step 1: Find Your WordPress Root Directory

**If using LocalWP:**
1. Open **LocalWP**
2. Right-click your **"sperling"** site
3. Click **"Open Site Shell"**
4. Type: `pwd` (shows current directory)
5. Or manually navigate to: `C:\Users\pwilk\AppData\Roaming\Local\sites\[your-site-name]\app\public\`

**If using live site:**
- Upload to your hosting's WordPress root (same folder as `wp-config.php`)

### Step 2: Upload the Script

1. **Copy `setup-complete-site.php`** from this repository
2. **Upload it to your WordPress root directory** (same folder as `wp-config.php`)

### Step 3: Run It

**Option A: Via Browser (Easiest)**
1. Make sure you're **logged into WordPress admin**
2. Visit: `https://sperlinginsurance.local/setup-complete-site.php`
   - (Replace with your actual site URL)
3. You'll see a progress page showing all pages being created
4. **Done!** All pages are now live

**Option B: Via LocalWP Terminal**
1. Open LocalWP → Right-click site → "Open Site Shell"
2. Navigate to WordPress root: `cd app/public`
3. Run: `php setup-complete-site.php`
4. Done!

### Step 4: Delete the Script

**IMPORTANT:** After running successfully, **DELETE** `setup-complete-site.php` for security!

## 🆘 Troubleshooting

**"You must be logged in as administrator"**
- Make sure you're logged into WordPress admin
- Or access the script while logged in

**"Template not found" errors**
- Make sure all template files are in your theme folder
- Check that theme is active

**Pages not showing**
- Check WordPress Admin → Pages
- Verify pages are published (not draft)
- Clear any caching
