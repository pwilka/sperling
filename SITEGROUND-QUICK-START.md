# ⚡ SiteGround Quick Start - 3 Steps

## Step 1: Upload Script
1. Log into **SiteGround** → **Site Tools** → **File Manager**
2. Navigate to WordPress root (where `wp-config.php` is)
3. Click **"Upload Files"**
4. Upload `setup-complete-site.php`

## Step 2: Run It
1. Make sure you're **logged into WordPress admin**
2. Visit: `https://sperlinginsurance.com/setup-complete-site.php`
3. Watch it create all pages!

## Step 3: Delete Script
1. Go back to **File Manager**
2. **Delete** `setup-complete-site.php` (security!)

---

**Done! All pages are now live! 🎉**
